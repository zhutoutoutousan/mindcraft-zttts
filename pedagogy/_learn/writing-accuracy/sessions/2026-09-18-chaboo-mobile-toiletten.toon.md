  So augenblick gebe ich ein kurz 插播 ein → So, im Augenblick schiebe ich kurz einen Einschub ein (im Augenblick statt nacktem augenblick — schon zweite Rückkehr; einschieben mit Präfix am Ende; kurzer Einschub ist das deutsche Wort für 插播)
  daß → dass (RÜCKFALL: 2026-09-12, heute zweimal; Konjunktion immer ss, nie ß)
  es fast immer so gibt möblierte Toilette → es fast immer mobile Toiletten gibt (Nebensatz: gebeugtes Verb ans Ende; mobile Toilette/Toilettenwagen statt möblierte — der Wagen ist zufällig auch möbliert, aber gemeint ist beweglich; Plural)
  neben der Festivals → neben den Festivals (Dat. Pl.: den; das Nomen auf -s nimmt kein zusätzliches -n)
  Ich glaube wie funktioniert es geschäftlicherweise → Ich frage mich, wie das geschäftlich funktioniert (Ich frage mich für I wonder; geschäftlich statt erfundenem -weise-Adverb; wie-Satz mit Verb am Ende)
  Merken Sie irgendwo innerhalb den System ja → Notiere das irgendwo im System, ja? (notieren = schriftlich merken lassen; du-Form; im System oder innerhalb des Systems (Gen.), nie innerhalb den)
