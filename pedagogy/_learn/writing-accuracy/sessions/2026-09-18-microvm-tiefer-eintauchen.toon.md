errors_brief[10]:
  Auf wem bestehen MicroVM → Woraus bestehen MicroVMs (bestehen aus + Dat.; Fragewort woraus; Plural MicroVMs)
  diesem eintauchen → diesem Eintauchen (substantiviertes Verb großschreiben)
  zwei neues Schwerpunkts → zwei neue Schwerpunkte (Zahlwort → starke Adjektivendung -e; Nomen ohne -s)
  d.h. → d. h. (Leerzeichen nach dem Punkt)
  cedae → Cedar (Eigenname wie das Holz)
  auf multi-tenant VM geläuft wird → läuft auf einer Multi-Tenant-VM (laufen ist stark: läuft; auf + Dat.)
  würde die Umgebung von verschiedenen Ausführungen verschmutzt → wird die Umgebung durch verschiedene Ausführungen verschmutzt (Passiv braucht werden/wird; durch markiert den Verursacher)
  in Order to Umgebungsverschmutzung zu vermeiden machen wir es → Um Umgebungsverschmutzung zu vermeiden, machen wir das (um…zu statt EN-Kalk; Komma vor dem Hauptsatz; das statt es)
  Begleiten Sie auch → Begleite das auch (du-Form, wie immer im Chat)
  YouTube Videos → YouTube-Videos (Durchkopplung mit Bindestrich)
